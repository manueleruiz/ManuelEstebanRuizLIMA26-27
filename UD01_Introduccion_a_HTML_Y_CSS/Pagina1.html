Capitulo 1

Etiquetas HTML

Para comenzar a crear as nosas paxinas web o unico que tenemos que facer e ir compoñendo as diferentes etiquetas HTML dun documento. Unha etiqueta HTML e un termo rodeado por un signo de menor e outro de maior

Estructura basica denha paxina

As paxinas web manteñen unha estrutura moi sinxela que debemos respectar para que os navegadores sexan capaces de presentala. Non podemos comenzar a nosa paxina cunha etiqueta de parrafo, por ejemplo senon que debemos indicar que tipo de paxina estamos xenerando, que informacion adicional levara e onde comenza o contido que debe ser amosado.

Capitulo 2

Titulos e parrafos

A lenguaxe HTML e moi coidadosa coa organizacion da informacion, polo que o primero que debemos coñecer e como estruturar os titulos e como definir os parrafos del texto.

Parrafos

As etiquetas p y /p empreganse para definir un bloque de texto que se comporta como un parrafo. Normalmente non deixaremos nunca unha porcion de texto solta pola paxina web, senon que a rodearemos con esas etiquetas.

Titulos

As etiquetas desde (h1 a h6) utilizanse para definir un texto como titulo, indicando que é unha cabeceira que queremos destacar sobre o resto do texto. Tenemos 6 opciones para definir titulos, de maior a menor importancia. Unha paxina web ben diseñada contará con estos encabezamentos para definir os distintos apartados do texto, cos seus diferentes niveles.
